## 2. Features Implemented / Promised in the Backend Codebase (`backend/app/`)

### 2.1 Database Schema (`backend/app/database.py`, `backend/app/models.py`)
All 10 SQLAlchemy tables compile cleanly for both SQLite (`WAL` mode, `busy_timeout=5000`, `PRAGMA foreign_keys=ON`) and PostgreSQL (`normalize_database_url` rewriting `postgres://` and `postgresql://` to `postgresql+psycopg2://`):

1. **`educational_contexts` (`EducationalContext`)**: 7 explicit context fields (`subject`, `grade`, `country`, `curriculum_name`, `language`, `year`, `edition`), `ui_language`, teacher metadata (`teacher_name`, `school_name`, `section_name`, `planning_date`), schedule defaults (`school_days`, `holidays`, `default_period_Minutes`, `default_periods_count`), `selected_tools`, `document_preferences`, `active_template_id`, optimistic `version`, and **`owner_id` (default `"teacher_default"`, Batch 6 schema hook — currently unused for auth/filtering)**.
2. **`phase_templates` (`PhaseTemplate`)**: Reusable period/phase structures per context (`periods_count`, `period_minutes`, `phases` JSON, `is_default`).
3. **`curriculum_sources` (`CurriculumSource`)**: Source records (`title`, `file_name`, `file_path`, `sha256_fingerprint`, `file_size_bytes`, `page_count`, `extraction_status`, `book_year`, `edition`, `source_url`, `is_official_claimed`, `official_evidence`, `reviewer_name`, `review_notes`, `verification_status`, `index_approved`, `version`).
4. **`source_pages` (`SourcePage`)**: Per-page PDF extraction (`pdf_page_number`, `printed_page_number`, `extracted_text`, `corrected_text`, `has_extractable_text`, `ocr_ambiguities`, `human_reviewed`).
5. **`chapters` (`Chapter`)**: Book chapters linked to context/source (`title`, `order_index`, `pdf_start_page`, `printed_start_page`, `content_origin`, `is_documented`).
6. **`lessons` (`Lesson`)**: Lesson library (`title`, `code_or_order`, `pdf_page_number`, `printed_page_number`, `content_origin`, `objectives`, `prior_knowledge`, `activities`, `questions_and_solutions`, `evaluation_criteria`, `key_terms_or_quotes`, `review_status`, `version`).
7. **`plans` (`Plan`)**: Daily, Weekly, and Five-Day plans (`plan_type`, `status`, `context_snapshot`, metadata, `lessons_count`, `periods_count`, `period_minutes`, `total_allocated_minutes`, `objectives`, `prior_knowledge`, `teacher_role`, `student_role`, `teaching_tools`, `phases`, `formative_assessment`, `differentiation`, `homework`, `home_enrichment_minutes`, `references_note`, `planning_notes`, `subject_items`, `schedule_days`, `slides`, `presentation_settings`, `content_origin`, `version`, `approved_version`, `approved_by`).
8. **`plan_versions` (`PlanVersion`)**: Immutable version snapshots (`version_number`, `status_at_save`, `context_snapshot`, `plan_payload`, `content_sha256`, `reviewer_name`).
9. **`plan_reviews` (`PlanReview`)**: Audit snapshots (`plan_version`, `overall_status`, `blockers_count`, `warnings_count`, `passed_count`, `findings`).
10. **`export_tasks` (`ExportTask`)**: Export registry (`plan_version`, `export_format`, `file_name`, `file_path`, `content_sha256`, `file_size`, `review_status_snapshot`, `context_snapshot`, `source_status_snapshot`, `structural_check_passed`, `structural_check_details`).
